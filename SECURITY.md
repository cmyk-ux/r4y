# Security policy

Please do not report security vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** feature on this repository when available. Include the affected R4Y version/commit, backend, impact, and a minimal reproduction that does not contain game data, credentials, or personal files.

R4Y is experimental software that launches third-party runtime code. Do not run backend builds or executables from untrusted forks unless you have reviewed their source and understand the risk.
